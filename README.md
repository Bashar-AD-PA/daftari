# دفترِي — نظام محاسبي محلي

تطبيق محاسبي عربي للجوال، يعمل محلياً دون اشتراط الإنترنت.
تُحفظ بيانات كل جهاز في IndexedDB على الجهاز نفسه ولا تُرسل إلى خادم خارجي.

خارطة التطوير وقواعد الحفاظ على البيانات: [docs/ROADMAP.md](docs/ROADMAP.md).

- حسابات وعمليات (له / عليه) برصيد لكل عملة
- عملات وتصنيفات قابلة للإضافة
- إرفاق صور، بحث، كشف حساب بالرصيد التراكمي ومشاركته
- إغلاق الرصيد، نسخ احتياطي واسترجاع (ملف JSON)
- أرقام هواتف للحسابات مع زر اتصال مباشر
- شاشة «الديون المتأخرة»: حسابات لها رصيد مفتوح دون حركة منذ مدة محددة (15/30/60/90/180 يوماً) مع تنبيه «متأخر» في القائمة الرئيسية
